# 星际争霸重制版地图开发文档

<br />

《星际争霸 1》即《星际争霸》，加上数字 1 主要是为了区别《星际争霸 2》。  
《星际争霸》自 [1.18](https://news.blizzard.com/en-gb/starcraft/20674424/starcraft-brood-war-patch-1-18-patch-notes) 版开始可免费下载游玩。  
《[星际争霸：重制版](https://news.blizzard.com/en-gb/starcraft/20977641/starcraft-remastered-is-live)》是《星际争霸》1.20 版本之后的付费高清外观，可在最新版《星际争霸》中付费解锁。  
《星际争霸：重制版》也属于《星际争霸 1》。
